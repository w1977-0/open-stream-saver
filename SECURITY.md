# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch and to the latest published release when practical.

## Report a vulnerability responsibly

Please do not open a public issue for a potential vulnerability that could expose a local file, private-network service, user data, or authorization material. Instead, use GitHub’s private security-advisory feature for this repository. Include a minimal reproduction, affected version, operating system, expected and actual behavior, and any proof of impact. Remove credentials, cookies, tokens, private URLs, and protected media from your report.

## Security focus

Reports are especially helpful for unsafe URL handling, private-network access, redirect handling, path traversal, temporary-file exposure, command injection, unsafe FFmpeg invocation, extension permission overreach, or data unexpectedly leaving the local machine.

## Out of scope

This project does not accept requests or reports framed as ways to bypass DRM, logins, subscriptions, paywalls, regional restrictions, or content-owner controls. Those are product-scope exclusions, not security defects.
